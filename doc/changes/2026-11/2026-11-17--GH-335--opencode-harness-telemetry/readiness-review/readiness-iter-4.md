## Verdict Rationale

The iteration-3 remediation is real and largely lands. DEC-15 is an honest settlement of the scope question rather than a dodge: it is recorded once, the claim is narrowed in every place that carries it, the narrowed criterion remains falsifiable from recorded invocation arguments and landed rows, and nothing in the artifacts still claims the shipped dispatch proves propagation. Findings 3–10 from iteration 3 are resolved, and the ones that touch machinery were re-verified against the delivered code and store rather than accepted on the artifacts' word: the union's truncation and cap shapes exist and are reachable, the contract inventory is bidirectional and currently lacks exactly the names Phase 2 adds, and both TDRs are correctly `Proposed`/R2/indexed with no dangling id. The arithmetic is clean — 46 TCs, 26 ACs, 8 phases, every gate path resolvable at its owning phase, every created file inside declared scope.

What blocks delivery is three holes opened by the amendment itself, all of the same family the gate has failed three times: a premise stated as true that the code or the environment does not support. The narrowed claim says a caller supplies an agent identity at the port; no contract member carries one and two artifacts name different resolvers, so the central oracle can only assert a binding the test itself built.
