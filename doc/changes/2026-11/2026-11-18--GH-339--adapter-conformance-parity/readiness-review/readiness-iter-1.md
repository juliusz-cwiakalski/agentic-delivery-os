   Suggested fix: decide one of (a) allow `recorded-difference` to carry the class that names the dimension (so GitLab `pagination-truncation` references a `pagination-model` entry on `(gitlab, read-pipeline-run)` — the same cell the parity basis already forces to be a declared difference), (b) add an explicit fourth posture such as `not-applicable-by-declaration` with a reason and restate AC-F2-10, or (c) scope the family's obligation to adapters whose named operation declares a bound, with the family→operation mapping fixed once (not per adapter) so the "unrelated gap" escape disappears.
