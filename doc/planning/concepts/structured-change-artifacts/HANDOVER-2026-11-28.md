## What is settled

- Five core facets: specification, test plan, delivery plan, PM context, handover. The
  milestone contract is deferred to `schemas/deferred/milestone.yaml`.
- The specification is a hybrid: a typed contract plus declared extension slots with a `useIn`
  audience and a word budget, plus progressive depth (`summary`, `detail`, `rationale`).
- The delivery plan carries a `contextFor` map per phase and role; the tool has a mandatory set
  per role, and the plan can add but never remove.
- Change resolution uses the worktree registry first; the branch name is a legacy fallback. One
  lane, one change. The ID is implicit by default and explicit when needed.
- The lifecycle is a gated state machine parameterized by a workflow template. The PM or CEO
  selects the template at intake and can add a state with a reason; it cannot remove a
  mandatory gate.
- Commit messages are deterministic: the phase title is the subject, the acceptance criteria
  are the body, the handover's done and deviations follow. The phase title is a verb phrase.
- Many tool commits on the change branch, one squash commit on the integration branch. The
  one-commit-per-change rule applies to the merge.
- Hand edits are attribution, not prohibition. A broken artifact can be repaired through
  `change repair`; the target is a tool-written share of 95 percent or more.
- The plan audit is a learning signal: record and learn, fail only a path outside the change's
  scope or in a protected area. The merge authority resolves an ordinary conflict.
- The handover is tool-drafted and coder-confirmed: five fields, three bullets each, 1KB.
- Delivery is one epic, multiple pull requests, one milestone. Slice 0 and slice 1 first, then
  slices 2 to 5; slice 6 is deferred.
- The delta protocol and the push model are deferred. The first version is stateless full
  bundles per role and phase.
- The output keeps semantic keys and drops YAML structure keys; tables carry the meaning.
- The total-function test plus an exception budget of three decides what the tool owns.
