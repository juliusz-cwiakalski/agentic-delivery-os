# Glossary

## Contributor Orientation

An evidence-backed introduction to a project's purpose, architecture, vocabulary,
setup, delivery, environments, observability, ownership, security/compliance, and a
contributor's first-work context. It composes Project Knowledge Management and is
distinct from Project Onboarding, which installs ADOS into an existing repository.

## Knowledge Gap

A durable, material deficiency in a canonical project-knowledge source or access
mechanism. A gap stores a sanitized diagnosis and lifecycle evidence, not the answer
or tracker workflow state. Repo-local identifiers use the proposed `KG-NNNN` form.

## Project Knowledge Management

The cross-cutting ADOS capability for authority-aware queries, explicit uncertainty,
bounded review, Contributor Orientation, and verified repair of Knowledge Gaps while
canonical knowledge remains in its owning source.

## Retrieval outcome

The explicit result of a bounded knowledge query: `answered`, `insufficient`,
`conflicting`, `inaccessible`, `not_configured`, or `not_found`.
