# Phase 2 drafting retrospective: evidence boundaries

## What happened

Integration brought two engine implementations into the review baseline.
Read-only tracker checks found GH-177 still open despite its merged PR.
Source inspection and a passing local license audit showed existing CI
enforcement, contradicting phase 0's missing-enforcement inference. Combined
docs also exposed duplicate metadata and conflicting glossary rows.

## What went well

Cross-checking actual specs, CI wiring, tracker and merged commits prevented
story completion from being confused with operational validation. Auditing
the mined rows kept documented constraints from becoming invented decisions
or a permanent shared-hotspot union convention.

## Pattern to repeat

At each gate, report four states separately: implemented artifact, tracker
closeout, owner ratification, and observed outcome. Reconcile changed sources
before drafting; quote exact story AC for cross-cutting representation and
label uncovered concerns as proposals. A semantic combined-content review
and strict metadata parse complement a successful textual merge.

## Caution

This lesson comes from phase 2 drafting, not a completed phase or pilot.
Permanent graduation and correction routes still require gate 2 decisions.
