Add the second executable identity and its local install posture: a `jaiship`
bin beside `delivery-os` over one shared launcher composition and one resolver,
a read-only prior-identity fallback for project configuration and the host state
root with one bounded `prior-identity-fallback` notice per source kind per
composed program, the state-free `--print-install-path` self-description, and a
user-level launcher registered at the brand install path. The compatibility
alias, the package scope, the repository and docs URLs, the MCP default, and the
installer's own pre-freeze surface are unchanged.
