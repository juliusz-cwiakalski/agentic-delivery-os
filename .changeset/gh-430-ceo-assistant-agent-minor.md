Add the `ceo-assistant` agent to the agents pack: a low-cost executor for
`@ceo` that carries out one briefed task per run and returns a short evidence
report. It holds the CEO's access and none of its decision authority, pushes
only a branch the brief names exactly, and never merges, releases or deploys.
`@ceo` gains a delegation section that states when to delegate, what it never
delegates, and how to read the report. The role is registered as an execution
seat on both provider profiles and in the model configuration, the inventory,
the docs and the uninstall list, and the suites that pin the seat matrix and
the roster cover twenty-five roles. The definition sets no model: the model is
the `ceo-assistant` seat of the provider profile, or the harness configuration.
